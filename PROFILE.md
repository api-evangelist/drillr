# drillr Public Data API

drillr is a financial data and research API for the US, China and Japan. It provides financial statements, full-text filing search, natural-language company discovery, and research signals extracted from filings, news and earnings calls. The same data is served two ways: a REST API for scripts and pipelines, and a hosted MCP server for AI agents, with every reported figure linking back to its source document.

- **Provider:** https://drillr.ai
- **Documentation:** https://drillr.ai/docs
- **Base URL:** https://gateway.drillr.ai/api/v2
- **Tags:** financial-data, equities, sec-filings, fundamentals, earnings, ownership, corporate-events, analyst-ratings, news-signals, mcp, agent-native
- **Public API:** yes
- **Agent-native (MCP / llms.txt / skills):** yes
- **Confidence:** 90/100

## APIs

- **drillr REST API** — REST API exposing ~29 endpoints across company discovery, filings, signals, events, ownership, executives, financials, earnings, prices and analyst data for US, China and Japan. API-key header auth (X-API-KEY). Returns JSON with source-linked rows. (`https://gateway.drillr.ai/api/v2`)
- **drillr Data MCP Server** — Hosted Streamable HTTP MCP server (drillr-data) exposing the same financial data as ~10 agent-callable tools covering discovery, filings, signals and arbitrary SQL. Browser OAuth auth, no API key needed. (`https://gateway.drillr.ai/mcp/data`)

> Both a REST API (base https://gateway.drillr.ai/api/v2, X-API-KEY auth) and a hosted MCP server (https://gateway.drillr.ai/mcp/data, Streamable HTTP, browser OAuth) are confirmed live via drillr.ai docs. The declared OpenAPI spec at https://gateway.drillr.ai/api/v2/openapi.json and llms.txt at https://drillr.ai/llms.txt are asserted in the submitted apis.json but could NOT be independently retrieved this session, so they are not cataloged as verified properties. A public GitHub repo (Little-Grebe-Inc/drillr-mcp-server) shows an alternate Bearer-key auth and a v1 /api/v1/data/run_sql endpoint; treat the drillr.ai v2 docs as canonical.
